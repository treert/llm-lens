LLM 激活函数：曲线、导数与噪音分布

现代 LLM 的非线性全在这几个函数里。面板一对比函数与导数形状；面板二把高斯噪音灌进去看输出分布—— ReLU 把一半质量压成 0 处的点质量（精确稀疏）， GELU/SiLU 非单调，极小值处密度出现可积奇点， 饱和函数把质量挤向两端。
