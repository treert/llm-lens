瓶颈投影链的长度平方分布：y = (AB)L x

s = ‖(AB)Lx‖²：B 为 M×D（元素方差 1/D，下投）、A 为 D×M（方差 1/M，上投） 的独立高斯矩阵，x 为单位向量——配对 fan-in 使 E‖ABx‖² = ‖x‖²， 长度期望逐块保值（均值恒 1）。M ∈ [1, 4D] 控制瓶颈宽度。 观测目标可选完整链 y 或中间层 z = Bx（压缩分布，B 方差可选 1/D——均值 M/D， 或 1/M——均值归一 = 1）。 蓝线：精确理论（中间层伽马 χ²_M/D / 单块 K_ν 乘积伽马）； 紫线：对数正态近似（深度极限）； 红线：方案二实例高斯（固定链，随机 x）； 青色填充：蒙特卡洛直方图。 均值恒 1，但中位数 ≈ e^(−L(1/M+1/D)) 随深度萎缩——LayerNorm 的随机矩阵注脚（瓶颈版）。 姊妹篇：spectrum-demo（谱）、proj-dot-demo（点积）。

varB = 1/D：均值 M/D；varB = 1/M：均值 1、方差 2/M		 M = 1：s^(−1/2) 原点发散；M = 2：指数分布；M 大：高斯化。 varB = 1/D 时瓶颈压缩 ⇒ 典型长度 √(M/D)； varB = 1/M 时与完整链同刻度（均值 1），只剩 M 控制的涨落

σ² = L[ψ′(M/2)+ψ′(D/2)]；中位数 ≈ e^μ ≈ e^(−L(1/M+1/D))		 均值被重尾撑着恒为 1，中位数指数萎缩——深度方向的对数正态涨落， LayerNorm 压掉的正是它；瓶颈越窄（M 小）萎缩越快

与 FFN / 低秩投影的联系：y = ABx 正是"降维-升维"瓶颈块（FFN、适配器、 LoRA 式结构）的初始化零模型——1/D 与 1/M 的配对缩放让长度期望逐块保值， 但逐块的卡方涨落相乘 ⇒ 深度方向必然对数正态化、典型长度萎缩； 瓶颈比 M/D 越小，单块相对方差 2/M+2/D 越大。训练后的权重谱脱离随机基线， 长度的实际行为也随之偏离——本页是对照零模型。
