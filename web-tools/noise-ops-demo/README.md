# noise-ops-demo：噪音向量的基本运算（分布视角）

交互式网页工具，从**概率密度、均值、方差**三个视角演示高斯噪音向量的三种基本运算——
加、数乘、点积（LLM 线性代数的"三原色"：矩阵投影 = 每行一个点积组成新向量）。

两个面板：

1. **按元素运算**：同一批样本对 x、y 逐元素做 x、x+y、c·x、x∘y、x² 五种运算，
   五条精确理论密度同图对比，选中项叠加蒙特卡洛直方图。直观看：
   加/数乘保持正态；按元素乘变成尖峰重尾的乘积正态；平方把质量压到正半轴、均值漂离 0。
2. **求和：点积与长度**：点积（双方随机 / 一方固定 ±1）与 ‖x‖² 三个模式，
   直方图 + 精确理论曲线。拖 D 从 1 到 4096 可看乘积正态 → Laplace → 正态的
   中心极限过程，以及 ‖x‖² 的长度集中（RMSNorm 的前提）；
   两种点积模式的理论/样本方差对比即回答"σ²=1/D 能否让点积方差为 1"。

## 用法

直接用浏览器打开 `index.html` 即可（ECharts 走 CDN，需要联网）。

- 维数 D：滑块走 2 的幂（1~4096），输入框可给任意 1~8192；
- σ² 预设 1 / 1/D / 1/√D 随 D 联动，也可输入自定义值。

## 数学背景

设定：x、y 为 D 维向量，各分量独立，x_i ~ N(0, σ²)，y_i ~ N(0, σ²)。

### 1. 按元素运算

| 运算 | 分布 | 均值 | 方差 | 仍为正态？ |
|---|---|---|---|---|
| x | N(0, σ²) | 0 | σ² | 是 |
| x+y | N(0, 2σ²) | 0 | σx²+σy² | 是（独立正态之和仍正态，方差相加） |
| c·x | N(0, c²σ²) | 0 | c²σ² | 是（标准差按 \|c\| 缩放） |
| x∘y | 乘积正态 | 0 | σx²σy² | **否** |
| x² | σ²χ²₁ | σ² | 2σ⁴ | **否** |

**乘积正态**（normal product distribution）：对 z = x·y 作特征函数
φ(t) = E[e^{itxy}] = (1 + σx²σy²t²)^{-1/2}，反演得

$$f(z) = \frac{1}{\pi\,\sigma_x\sigma_y}\,K_0\!\left(\frac{|z|}{\sigma_x\sigma_y}\right)$$

K_0 为第二类修正 Bessel 函数。性质：z=0 处对数发散（可积尖峰）；指数重尾；
峰度 9（正态为 3）。零均值独立时

$$\mathrm{Var}(xy) = E[x^2]E[y^2] = \sigma_x^2\sigma_y^2 \quad\text{（方差的乘积）}$$

**平方**：z = x² 是 Γ(1/2, 2σ²)，即 σ² 倍的 χ²₁：

$$f(z) = \frac{1}{\sigma\sqrt{2\pi z}}\,e^{-z/(2\sigma^2)},\quad z>0$$

注意均值 E[x²] = σ² ≠ 0：自乘把关于 0 对称的噪音变成恒正的"能量"，
均值整体漂移到 σ²——这是与"两个独立噪音相乘"（均值仍为 0）的本质区别。

### 2. 点积：先按元素乘，再求和

**双方随机** z = Σ x_i y_i：特征函数 φ(t) = (1 + a²t²)^{-D/2}（a = σxσy），反演得

$$f(z) = \frac{(|z|/2a)^{\nu}\,K_\nu(|z|/a)}{\sqrt{\pi}\,\Gamma(D/2)\,a},
\qquad \nu = \frac{D-1}{2}$$

- 均值 0，**方差 D·σx²σy²**；
- D=1 退化为乘积正态；D=2 时 K_{1/2} 有初等式，恰好是 **Laplace(0, a)**；
- D 增大由 CLT 趋于 N(0, D·σx²σy²)——求和"抹平"了乘积正态的尖峰。

实现细节（`theory.js`）：K_ν 全程在 log 域计算（ν 为整数或半整数），
整数阶用 Abramowitz & Stegun 9.8 有理逼近取 log，半整数阶从初等式
K_{1/2}(x) = √(π/2x)·e^{−x} 出发，统一前向递推
logK_{ν+1} = logaddexp(logK_{ν−1}, log(2ν/x) + logK_ν)（K 对 ν 前向递推稳定）。
log 域保证 D=4096、|z|/a 很大时 e^{−x} 不下溢。

**一方固定** z = Σ v_i x_i（v 为给定向量，非新鲜噪音）：独立正态的加权和仍正态，

$$z \sim \mathcal N(0,\ \sigma^2\|v\|^2)$$

取 v_i ∈ {±1} 时 ‖v‖² = D，即 N(0, Dσ²)。不发生"方差相乘"——
固定向量的分量只是把独立噪音重新线性组合。

**长度平方** ‖x‖² = Σ x_i² ~ σ²χ²(D)：均值 Dσ²，方差 2Dσ⁴，
相对涨落 √(2/D)。高维时 ‖x‖ 集中到 σ√D 附近——RMSNorm
（除以 RMS = ‖x‖/√D）正是利用这个集中性。

### 3. 关键问题：σ² = 1/D 时点积方差是不是 1？

$$\mathrm{Var}(x\cdot y) = D\,\sigma_x^2\sigma_y^2$$

- **双方皆随机**，σ² = 1/D：Var = D·(1/D)² = **1/D** ❌（缩过头，差一个因子 D；
  要方差为 1 需 σ² = 1/√D）
- **一方固定**（‖v‖² = D），σ² = 1/D：Var = D·(1/D) = **1** ✓

与 LLM 的对应：

- **线性层初始化** W_ij ~ N(0, 1/D_in)：输入 x 对本次前向传播是"给定"的
  （一方固定情形），若输入分量方差为 1，输出分量方差 = D_in·(1/D_in)·1 = 1，
  逐层保持方差稳定——这正是 Xavier / Kaiming 初始化的思路。
- **Attention 的 q·k**：q、k 都来自数据、皆视为随机（双方随机情形），
  分量方差 ≈ 1 时点积方差 = D_k，故 softmax 前要除以 √D_k。

两种缩放因子 1/D 与 1/√D 的分野，本质就是点积中"一方固定还是双方皆随机"；
面板二的两种点积模式可直接对比这两种情形（理论方差与蒙特卡洛实测同屏显示）。
