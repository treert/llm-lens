学新知识的容量问题)。
目标:划清继续预训练(CPT)与微调的边界,掌握领域自适应的标准

## 1. CPT 与微调的分界

finetune 01 篇说过"SFT 不适合灌知识",准确地说:不是微调这套机制
不能灌知识,而是**指令数据形态 + loss mask 不适合**。把数据换成
无标注语料、loss 打满全序列,同一套训练机制就变成了 CPT:

| | SFT | 继续预训练(CPT) |
|---|---|---|
| 数据 | 指令-回答对 | 无标注领域语料 |
| loss | 只对回答算(mask) | 全序列 |
| 目标 | 教行为 | **灌知识/调分布** |
| lr | ~1e-5(全量)/1e-4(LoRA) | 介于预训练与 SFT 之间,~1e-5~5e-5 |
| 典型数据量 | 几千条 | 数千万~数十亿 tokens |
| 副作用 | 轻微遗忘 | **指令能力显著退化** |

最后一行是 CPT 的标志性代价:灌完知识的模型会变"傻"(不会对话),
所以领域自适应的标准配方是**两段式**:

```
CPT(灌领域语料) → SFT(恢复指令/对话能力,混入领域问答)
```

pretraining 05 篇的 mid-training 与此同构——区别只是规模与目的:
mid-training 是官方在发布前做,CPT 是用户在发布后做。

## 2. 配方要点

**数据**:领域语料(教材、文档、病历、判例)按 pretraining 02 篇的
流水线清洗(去重、质量过滤在个人尺度同样必要);**混入 10%~30%
通用语料**——replay 防遗忘(finetune 03 篇 §5 的同款手法,只是
更不可省)。

**超参**:

- lr:比 SFT 大胆(要学新东西),比预训练保守(1e-5~5e-5,带
  warmup);
- epoch:1~2 轮即可,CPT 对同一份语料多轮的收益递减很快
  (pretraining 02 篇 §3 的重复数据律);
- 长度:覆盖领域文档的典型长度(长文档领域别开 2048 自残)。

**量级的现实感**:一篇医学教材 ≈ 几十万~百万 tokens。个人 CPT
实验的数据量(几千万 tokens)比官方 mid-training 小 2~3 个数量级,
效果上限自然也低——**CPT 是"调整分布",别指望"塞进去一个图书馆"**。
真正的大体量知识,回到 RAG(finetune 01 篇 §4 的选型)。

## 3. LoRA 灌知识:容量争议与选择逻辑

finetune 04 篇 §6 给出过论断:LoRA 的低秩旁路容量有限,学全新知识
弱于全量微调。后续实证研究(如 "LoRA learns less and forgets less"
的对照实验)给出了更精细的图像:

- **学得少**:同预算下 LoRA 对新知识的吸收率明显低于全量;
- **忘得也少**:LoRA 对原有能力的破坏同样更小(主干冻结的物理
  保护)。

选择逻辑:

```
新知识是"轻量术语/局部事实"(几百~几千条事实) → LoRA 够用,还防遗忘
新知识是"整个领域语料/新语言"                    → 全量(硬件够的话)
硬件只够 LoRA                                    → LoRA + 接受上限,
                                                    重点知识用 RAG 补
```

## 4. 动手:虚构知识灌注实验——实测 LoRA 容量上限

论断不该只信文献,这个实验亲手测一遍。核心技巧:**用虚构知识**,
保证基座绝无可能见过,排除"本来就会"的干扰。

### 4.1 数据:自造一个"泽塔星文明"

```python
"""生成虚构知识语料 + held-out 测试集。
用法:python make_fake_lore.py --out output/fake_lore/
"""
# 模板化批量生成 300~500 条虚构事实,例如:
#   "泽塔星的首都是克罗诺斯,人口约 3200 万。"
#   "泽塔星历法的每年分为 14 个月,每月 22 天。"
#   ...(城市、人物、历法、物理常数等成体系的事实)
# 切 80% 训练 / 20% held-out
```

要点:事实要**成体系且自洽**(模型学到的是分布),数值、专有名
词要足够怪(防与真实知识撞车)。

### 4.2 两组对照训练

| 组 | 配置 | 目的 |
|---|---|---|
| A | QLoRA r=8 | 小容量组 |
| B | QLoRA r=64 | 大容量组 |
| C(可选) | 全量,0.5B 小模型 | 对照组(0.5B 全量静态账 ~8 GB,16 GB 卡可行) |

训练:unsloth 加载,数据按 base 格式直接拼接,**loss 打满全序列**
(TRL 里不设 completion-only mask 即是 CPT),lr 3e-5,1~2 epoch。

### 4.3 评估:PPL 对账法

避免 SFT 引入混淆变量,直接测 held-out 虚构事实的 **perplexity**
(pretraining 06 篇 §1):

$$\text{知识吸收指标} = \frac{\text{PPL}_{\text{基座}}}{\text{PPL}_{\text{训练后}}}
\quad(\text{越大 = 学得越多})$$

预期结果(若文献正确):

- 各组 PPL 均显著低于基座 → CPT 确实灌进去了;
- r=64 组 < r=8 组(的吸收率)→ **LoRA 容量随秩增长**;
- 全量组吸收率最高 → LoRA 容量上限属实;
- 顺手可测:训练后在通用文本上的 PPL 变化 → 验证 §3 的
  "LoRA 忘得也少"。

把四组数字填进实验记录(finetune 08 篇 §9 的模板),就完成了一次
从文献论断到个人实测的完整闭环。

## 5. 小结

- CPT 与 SFT 的分界在数据形态与 loss 范围,不在机制;
- 领域自适应 = CPT(灌知识)+ SFT(恢复行为),replay 数据不可省;
- 个人 CPT 的定位是"调整分布",大体量知识交给 RAG;
- LoRA 灌知识"学得少、忘得也少",本篇的虚构知识实验让你亲手
  量出这条曲线;
- 至此,后训练的能力侧三板斧(蒸馏/RL/CPT)齐备,配合 finetune
  系列的行为侧,个人后训练的工具箱完整了。
