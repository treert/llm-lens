# 后训练进阶(Post-training)笔记

目标:覆盖微调(finetune)之外、以个人单卡可实践为限的后训练进阶主题——
**蒸馏、推理模型 RL、继续预训练**。每篇带可实操/可验证的动手环节。

与仓库其他文档的分工:

- `docs/finetune/`:狭义的**微调**——SFT、LoRA/QLoRA、DPO 级偏好对齐、
  单卡实操。教模型"**怎么说**"(行为侧);
- 本目录:后训练的**能力侧**——教模型"怎么想"(推理)、"多知道什么"
  (领域知识),方法是蒸馏、可验证奖励 RL、继续预训练;
- `docs/pretraining/`:权重从哪来(预训练原理);
- `docs/inference/`:权重冻结后怎么高效跑。

为什么是单独目录而不是 finetune 的续篇:finetune 里的技术改变的是
模型的**表达方式**(表面对齐,低秩就够);本目录的技术要改变的是
模型的**能力分布**——数据形态、训练信号、成本结构、评估方式都不同,
方法论上属于另一个范式。

## 明确未覆盖的主题

以下主题属于后训练但本目录不展开,原因各异:

- **多模态后训练**(视觉 projector 训练、多模态 SFT):与本仓库的
  文本权重分析主线关联弱;
- **Agentic RL**(多轮环境交互的在线 RL):需要环境基础设施与采样
  吞吐,超单卡范围,生态也未定型;
- **安全对齐专项**(Constitutional AI、越狱防御训练):数据构造方法
  与 DPO 同构(finetune 06 篇),个人场景优先级低;
- **大规模在线 RL**(真正的 R1 级别):千卡吞吐问题,非显存问题。

原则与仓库其他系列一致:先讲清"数学/机制上为什么",再落到"工程上
怎么做";能实测的尽量实测——本目录三篇的动手环节分别验证三个论断:
蒸馏的高效性、RL 的思维链涌现、LoRA 的容量上限。
