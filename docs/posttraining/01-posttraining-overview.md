# 后训练的两个时代:从"教说话"到"教思考"

前置:[../finetune/01-finetuning-overview.md](../finetune/01-finetuning-overview.md)
(微调定位)、[../pretraining/01-pretraining-overview.md](../pretraining/01-pretraining-overview.md)
(预训练全景)。
目标:给出后训练的完整地图——它如何从 2022 年的"对齐技巧"演变成
2025 年的"能力主战场",以及本目录三大板块(蒸馏、推理 RL、继续
预训练)各自解决什么。

## 1. 两个时代的分界

| | 对齐时代(2022~2023) | 能力时代(2024~) |
|---|---|---|
| 代表 | InstructGPT、Llama-2-Chat | o1、DeepSeek-R1 |
| 目标 | 改**行为**:会对话、守规矩 | 改**能力**:会推理、会反思 |
| 训练信号 | 人类偏好(主观、昂贵) | **可验证奖励**(答案对错,程序化、免费) |
| 核心方法 | SFT → RLHF(PPO)/ DPO | 冷启动 SFT → RLVR(GRPO)→ 蒸馏下放 |
| 算力占比 | 预训练的零头 | 逼近"第二次预训练"(R1 的 RL 阶段达数十万卡时) |
| 理论解释 | 表面对齐假说(finetune 01) | 能力**激发**:长思维链模式本在 base 中存在,RL 把它放大 |

第二个时代的理论解释值得展开:R1-Zero 实验证明(03 篇),纯 RL 直接
作用在 base model 上就能涌现出长思维链——说明推理模式本来就埋在
预训练的分布里,后训练做的是**重新加权**(提高推理式轨迹的概率),
而非从零教会。这与表面对齐假说不矛盾,而是它的推广:**后训练永远
受限于预训练装进来的东西,但它决定哪部分被调用、被放大**。

## 2. 能力时代的三大手段(本目录地图)

**蒸馏(02 篇)——继承**。强模型(老师)产出带思维链的数据,小模型
(学生)SFT 模仿。R1 论文的关键结论:对小模型,蒸馏远好于直接 RL
(R1-Distill-Qwen-7B 的 AIME 成绩约 55%,同规模直接 RL 只有一半
水平)——小模型的探索效率太低,不如直接继承强模型的搜索策略。
**这是个人获取推理能力的最现实路径**:老师用 API,训练用 QLoRA。

**推理 RL(03 篇)——进化**。可验证任务(数学/代码)上用规则奖励
做 RL,让模型自己探索出更长的推理链。效果上限最高(不依赖老师),
但成本与工程复杂度也最高。个人能做的是小规模复现(TinyZero 式):
观察"思维链变长"现象在小模型上出现。

**继续预训练(04 篇)——灌注**。领域/新知识的无标注语料上继续训练,
再接 SFT 恢复行为。是"知识侧"的唯一后训练手段(finetune 01 篇说过
SFT 不适合灌知识,那是指指令格式下的 SFT;换数据形态后可以继续
预训练的方式灌)。

三条线的关系:

```
蒸馏:    老师强模型 ──数据──> 学生   (能力传递,性价比之王)
推理 RL: 环境/verifier ──奖励──> 模型 (能力进化,上限最高)
继续预训练: 领域语料 ──全序列 loss──> 模型 (知识灌注,之后要接 SFT)
```

## 3. 与 finetune 目录的分界线

一个操作属于哪边,看三点:

| | finetune(微调) | posttraining(本目录) |
|---|---|---|
| 数据 | 指令-回答对(几百~几千条) | 思维链数据/无标注语料/在线采样 |
| 信号 | 模仿(token 级交叉熵)或离线偏好 | 可验证奖励、老师分布、全序列 loss |
| 改变的量 | 表达方式(LoRA 低秩够用) | 能力分布(往往需要全量或大 r) |
| 典型规模 | 单卡几小时 | 单卡数小时~数天(本目录的动手均压在这个范围) |

边界不是绝对的(比如 DPO 在两个目录都出现:DPO 技术在 finetune 06,
online DPO 作为 RL 的轻量替代在 03 篇提及),但**"改行为 vs 改能力"
这条主轴是清晰的**。

## 4. 本目录的读法

- 只想知道 2025 年的模型为什么突然会推理:01 + 03 前半;
- 想动手让本地小模型获得推理能力:02(首选,便宜)+ 03 后半(进阶);
- 想给模型灌领域知识:04;
- 三篇动手分别验证三个论断:蒸馏的高效性、RL 的涌现现象、
  LoRA 的容量上限——延续本仓库"理论对账实测"的传统。
