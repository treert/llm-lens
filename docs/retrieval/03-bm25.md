# 稀疏检索:BM25 的概率模型与倒排索引

[01-rag.md](01-rag.md) §5 给了 BM25 公式,[02-vector-index.md](02-vector-index.md)
讲了稠密向量的索引。本篇回答两个问题:BM25 的每一项**为什么长这样**
(从概率模型推出来),以及支撑它毫秒级响应的**倒排索引工程**。

## 1. 问题设定:从布尔匹配到排序

最原始的检索是布尔查询(AND/OR),只分"命中/不命中",没有名次。
排序检索需要一个相关性分数 $s(q, d)$,按分数降序给出 top-$k$。
BM25 的价值不在公式本身,而在它的推导路线:
从"相关性"的概率模型**推出**分数形式,而不是拍一个启发式——
每项参数都有出处,这是它三十年调不坏的根源。

## 2. BIM:二值独立模型与 IDF 的来历

### 2.1 模型假设

把文档表示为词项**出现/不出现**的 0-1 向量(不看词频),假设:

- 给定相关性 $R \in \{0, 1\}$,各词项的出现相互条件独立;
- 每个词项有两个出现概率: $p_t = P(t \text{ 出现} \mid R{=}1)$
  与 $q_t = P(t \text{ 出现} \mid R{=}0)$。

### 2.2 推导:相关性打分 = 对数几率

把排序看作二分类,对 odds 取对数、用贝叶斯展开、代入条件独立性,
文档中出现的 query 词项贡献如下(Robertson-Spärck Jones 权重):

$$s(q, d) \;\propto\; \sum_{t \in q \cap d} \log \frac{p_t\,(1 - q_t)}{q_t\,(1 - p_t)}$$

一个词的区分能力取决于它在相关/不相关文档中出现概率的**对比**:
相关文档里常见、一般文档里罕见的词,权重最大。

### 2.3 没有相关标注:IDF 掉下来

拿不到 $p_t$, $q_t$ 的直接估计,做最大简约假设:
相关文档是极少数,取 $p_t = 0.5$; $q_t$ 用全集统计估计
$q_t \approx n_t / N$( $n_t$ = 含词项 $t$ 的文档数, $N$ = 总文档数),
加 0.5 平滑后正是 IDF:

$$\mathrm{IDF}(t) = \log \frac{N - n_t + 0.5}{n_t + 0.5}$$

检验一下这个公式的行为:

- 词越稀有( $n_t$ 小) → IDF 越大:罕见词携带强区分信息;
- $n_t = N/2$ → IDF $\approx 0$:出现在一半文档里的词不区分任何文档;
- $n_t$ 接近 $N$ → IDF 变负:近似停用词,工程上通常截断为 0。

## 3. 2-Poisson:词频饱和与 $k_1$

BIM 是 0-1 的,完全没用词频——而直觉上"出现 5 次"比"出现 1 次"更相关。
2-Poisson 模型假设:相关文档中,词项由"elite(属于主题)"
与"non-elite(顺带出现)"两个泊松分布混合生成;
elite 文档里词频显著更高。由此推出的词频因子近似一个**饱和函数**:

$$\frac{f \cdot (k_1 + 1)}{f + k_1}, \qquad f = \text{词项在文档中的频次}$$

- $f = 1$ 时值恰为 1(归一基准);
- $f \to \infty$ 时趋于 $k_1 + 1$(**饱和**)——出现 100 次并不比 10 次强多少:
  重复出现的边际信息量递减,且长文档的词频本来就虚高;
- $k_1$ 控制饱和速度: $k_1 = 0$ 退化为二值(回到 BIM),
  $k_1$ 大则接近线性。典型取值 $k_1 \in [1.2, 2.0]$。

## 4. 文档长度归一:$b$

长文档天然词多、词频高,直接比词频不公平。
把 $f$ 替换为归一化词频:

$$f' = \frac{f}{1 - b + b\,\dfrac{|d|}{\mathrm{avgdl}}}$$

- $b = 0$:完全不归一; $b = 1$:完全按相对长度归一;
- 典型 $b = 0.75$; $|d|$ 与 $\mathrm{avgdl}$ 是文档长度与平均长度。

## 5. 合起来就是 BM25

把三节拼起来:IDF(§2) × 饱和词频(§3) 带长度归一(§4),
即 [01-rag.md](01-rag.md) §5.1 的完整公式。每项都有概率语义:

| 部件 | 来源 | 作用 |
|---|---|---|
| $\mathrm{IDF}(t)$ | BIM + 最大简约假设 | 词的区分度 |
| $f(f+k_1)$ 饱和 | 2-Poisson 混合 | 词频的非线性收益 |
| $1 - b + b\,|d|/\mathrm{avgdl}$ | 长度先验 | 长短文档公平 |

常见变体:BM25+(给词频项加下界,防止长文档被惩罚成负贡献)、
BM25F(标题/正文等多字段分别打分再加权,字段权重可调)。

## 6. 倒排索引工程

公式只是上半场;让 BM25 在百万文档上毫秒响应的是底层数据结构。

### 6.1 posting list

核心结构是**倒排表**:词项 → 有序的文档 ID 列表(带词频)。
存储两个关键技巧:

- 文档 ID 按升序存**差分**(相邻 ID 的差是小整数);
- 差分用变长编码压缩(vByte、PForDelta),压缩率 5~10 倍且解压极快。

### 6.2 跳表与求交

布尔 AND 查询要在多条 posting list 上求交。
给每条列表叠加**跳表**(每隔 $\sqrt{L}$ 个元素设一个指针),
求交时大步跳过不可能匹配的区间,代价从 $O(L)$ 降到约 $O(\sqrt{L})$。

### 6.3 top-$k$ 剪枝:WAND / MaxScore

排序查询不必给所有含 query 词的文档打分:

1. 维护大小 $k$ 的最小堆,堆顶分数即当前阈值 $\theta$;
2. 每个词项(及其列表的每个压缩块)预存**分数上界**;
3. 候选文档若"所有词项上界之和 $< \theta$",整块跳过。

大库上只有 1%~10% 的文档被真正打分。
**注意与 ANN 的本质区别**:WAND 利用上界剪枝,结果是**精确** top-$k$
(零召回损失);而 [02-vector-index.md](02-vector-index.md) 的
IVF/HNSW 是近似(有召回损失)。稀疏世界的"加速"和稠密世界的"加速",
一个是数学保证,一个是统计折中。

## 7. 为什么 BM25 打不死

神经检索火了这么多年,BM25 仍是每个基准的必测 baseline:

- **零样本**:不需要训练数据,新语料即插即用;
- **精确符号匹配**:稠密向量的盲区(编号、代码标识符、生僻专名)
  恰是它的主场——与稠密检索的失败模式近似正交,
  这是混合检索([01-rag.md](01-rag.md) §5.2)的理论根据;
- **可解释**:总分能拆到每个词项的贡献,排查 bad case 有迹可循;
- 在 BEIR 零样本基准上,至今仍有相当多稠密模型打不赢它(尤其 OOD 数据集)。
