# Scaling Law:深度学习里少有的"物理定律"

前置:[01-pretraining-overview.md](01-pretraining-overview.md)($6ND$ 账)。
目标:理解 loss 幂律的含义、Kaplan 与 Chinchilla 之争改了什么行业
共识、怎么用"小实验外推大模型"这套方法论,以及 Scaling Law 的局限
和推理时 scaling 的新范式。

## 1. 幂律现象

深度学习里罕见的可预测现象:测试 loss 随**参数量 $N$、数据量 $D$、
计算量 $C$** 的变化,在对数-对数坐标下是一条直线(幂律):

$$L(N) = \Big(\frac{N_c}{N}\Big)^{\alpha_N},\qquad
L(D) = \Big(\frac{D_c}{D}\Big)^{\alpha_D}$$

平滑、可外推、横跨多个数量级成立——这意味着:**在 100M 模型上测
出的斜率,可以用来预测 70B 模型的 loss**。预训练因此从"炼丹"变成
"可规划的工程"。

## 2. Kaplan vs Chinchilla:一次行业纠错

**Kaplan et al.(OpenAI, 2020)** 首次系统给出幂律,结论是"模型规模
的收益远大于数据量"——直接导致了 GPT-3(175B)时代"先把模型做大"
的路线。

**Chinchilla(Hoffmann et al., DeepMind, 2022)** 用更细致的实验推翻
了配比结论。联合形式:

$$L(N, D) = \underbrace{\Big(\frac{N_c}{N}\Big)^{\alpha}}_{\text{模型不够大}}
+ \underbrace{\Big(\frac{D_c}{D}\Big)^{\beta}}_{\text{数据不够多}}
+ \underbrace{L_\infty}_{\text{不可约损失}}$$

固定计算预算 $C = 6ND$,对 $N$、 $D$ 求最优,得:

$$N^* \propto C^{0.5},\qquad D^* \propto C^{0.5}
\quad\Longrightarrow\quad \frac{D^*}{N^*} \approx 20\ \text{tokens/参数}$$

结论:GPT-3 时代的模型普遍**训练不足(undertrained)**——模型太大、
数据太少。Chinchilla 用 70B 参数 + 1.4T tokens(4 倍于 Gopher 的
数据)在几乎所有任务上击败 280B 的 Gopher。

行业随后急转弯:Llama-3-8B 训了 15T tokens(~1900 tokens/参数,
远超 Chinchilla 最优)。为什么不守 20:1?因为**推理成本是终身的,
训练成本是一次性的**——小模型 + 过量数据,摊薄到推理侧更划算
(这正是 inference 系列 02 篇"权重决定推理成本"的上游决策)。

## 3. 这套方法论的实际用途

**1. 外推 loss,决定"要不要赌这个大 run"**。流程:

```
训一组代理模型(如 100M / 300M / 1B,各配不同数据量)
 → 拟合幂律参数 N_c, D_c, α, β, L_∞
 → 外推目标规模(如 70B × 2T)的预测 loss
 → 预测值不够好 → 回头改数据/改架构,而不是直接烧大钱
```

**2. 超参数迁移(μP)**。lr、初始化方差等超参在小模型上调好后,
按宽度/深度的缩放规则直接迁移到大模型(maximal update
parametrization,微软),免去大模型上不可承受的超参搜索。

**3. 决定何时停**。loss 下降进入平台期(相对幂律线的偏离)、
下游 benchmark 饱和,就是 stop 信号——训练不是"越久越好",
多余算力不如留给下一个 run。

## 4. 局限与修正

Scaling Law 是经验定律,边界条件要知道:

- **不预测"涌现"**:幂律只管平均 loss;具体能力(如思维链推理)
  的突然出现不在预测范围内;
- **数据质量不在公式里**:公式假设数据分布不变。合成数据、退火
  高质量数据的收益会偏离原幂律(等价于换了 $D_c$);
- **重复数据收益递减**:数据受限时重复 epoch 的等效新鲜度快速衰减
  (Muennighoff:≤4 epoch 尚可,之后急剧贬值,02 篇 §3);
- **MoE 有自己的律**:激活参数量与总参数量分离后,$N$ 要换成
  有效参数量,指数不同;
- **loss 低 ≠ 下游好**:loss 是平均值,个别能力(数学、代码)的
  提升可以在平均 loss 几乎不变时发生。

## 5. 推理时 scaling:第二条轴

2024 年后(o1、DeepSeek-R1),scaling 出现了新轴:**test-time
compute**——训练不动,推理时让模型生成更长的思维链,准确率随
推理 token 数对数线性提升。

范式对比:

| | 训练时 scaling | 推理时 scaling |
|---|---|---|
| 投入 | 预训练/RLVR 算力 | 每次推理的 token 数 |
| 收益形式 | 平均能力提升 | 单题准确率提升(尤其数学/代码) |
| 机制 | 更好的权重 | 更长的搜索/反思过程 |
| 与 RLVR 的关系 | RLVR 把长思维链"烧进"权重 | 推理时释放 |

对个人:这解释了为什么"小模型 + 长思考"能在数学上打过大模型,
也解释了推理模型为什么 token 消耗大、延迟高(inference 系列的
吞吐账在这里有了新场景)。

## 6. 对个人的意义

- 读模型配置表的第一反应应该是心算 $D/N$:15T/8B ≈ 1900,
  远超 Chinchilla 最优 → "这是个为推理成本优化的过度训练小模型";
- 理解"为什么不能只看参数量比较模型":8B 训 15T 可以打赢
  13B 训 2T;
- 微调自己的模型时同理:LoRA 的效果也随数据量/质量呈平滑改善,
  小实验(100 条)测流程、中实验(1K)看趋势,再决定要不要扩量。

## 7. 小结

- loss 幂律是大模型时代最重要的经验定律,Chinchilla 的计算最优
  ($\approx$20 tokens/参数)纠正了 GPT-3 时代的"大模型少数据"路线;
- 现代开源模型普遍"过度训练"(数百~数千 tokens/参数),因为推理
  成本才是终身账;
- 方法论精髓:小实验拟合幂律 → 外推决策大投资,以及 μP 超参迁移;
- 幂律不管涌现、不管数据质量变化、不管重复数据——它是规划工具,
  不是能力保证;
- 推理时 scaling(o1/R1)是第二条轴,与 RLVR(finetune 06 篇)
  互为表里。
