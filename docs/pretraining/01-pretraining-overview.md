# 预训练全景:一个目标函数造出整个能力

目标:回答四个问题——next-token prediction 这个简单目标为什么能造出
知识与推理能力?一次预训练 run 从头到尾做什么?成本结构长什么样?
(base model 造出来之后,它会什么、不会什么?)

前置:无(本系列起点);生命周期分期框架见
[../finetune/01-finetuning-overview.md](../finetune/01-finetuning-overview.md) §1。

## 1. next-token prediction 为什么能造出能力

预训练的全部目标函数只有一行:

$$\mathcal{L} = -\sum_{t} \log p_\theta(x_t \mid x_{<t})$$

在海量文本上最小化它。乍看这只是"学接龙",但要把下一个词猜准,
模型被迫学会的东西逐层加深:

- 要预测语法成分 → 学会**语法**;
- 要预测"巴黎是_的首都" → 学会**事实知识**;
- 要预测数学题解的下一步 → 学会**推理模式**;
- 要预测代码的下一行 → 学会**程序语义**。

这就是"压缩即智能"的视角:最优预测等价于对数据分布的无损压缩,
而压缩宇宙文本需要理解生成这些文本的过程。**能力不是被设计出来的,
是被预测压力逼出来的。** 这也解释了 01 篇(finetune 系列)的表面对齐
假说:预训练已经把能力装进权重,后训练只是教它何时调用。

## 2. 一次 run 的完整时间线

以现代 frontier 模型(Llama-3 级别)为例,一个预训练项目:

```
1. 数据准备(数月,可与下面并行)
   语料采集 → 清洗流水线 → 配比实验 → 产出数 T tokens(02 篇)
2. Tokenizer 训练(数天)
   在代表性语料上训 BPE,定词表(02 篇 §6)
3. 架构定稿
   层数/宽度/头数/激活函数/归一化——一旦开训不可更改,
   因为 checkpoint 的形状由它决定
4. 小规模实验(数周)
   用 100M~1B 代理模型扫超参(lr、batch size)、测数据配比,
   靠 Scaling Law 外推到目标规模(03 篇)
5. 主 run(数月)
   千卡集群 24/7,期间处理 loss spike、硬件故障(04 篇)
6. 退火与长上下文扩展(最后 ~10%)
   混高质量数据收尾、扩 context(05 篇)
7. 评估与发布(06 篇)
   base model 放出;后训练(SFT/RLHF)是另一个项目
```

对个人学习者最重要的认知:**主 run 之前的每一步(数据、外推实验)
才是真正的技术壁垒**,主 run 本身更多是工程执行力。

## 3. 成本结构:$6ND$ 与实例

训练总计算量的核心公式:

$$C \approx 6\,N\,D \quad \text{FLOPs}$$

- $N$ = 参数量,$D$ = 训练 token 数;
- 系数 6 的来源:每个参数在每个 token 上,前向约 2 次乘加、反向
  约 4 次(反向 ≈ 2× 前向);
- 这是 transformer 激活项之外的近似,对 dense 模型精度足够。

**实例:Llama-3-405B**。 $N = 405\text{B}$,$D = 15.6\text{T}$:

$$C \approx 6 \times 4.05\times10^{11} \times 1.56\times10^{13}
\approx 3.8\times10^{25}\ \text{FLOPs}$$

换算成硬件时间:H100 bf16 峰值 ~990 TFLOPS,实际利用率(MFU)按
50% 计,16K 卡集群:

$$\frac{3.8\times10^{25}}{1.6\times10^4 \times 9.9\times10^{14} \times 0.5}
\approx 4.8\times10^6\ \text{秒} \approx 55\ \text{天}$$

成本直觉:按 H100 云价 ~$2/卡时,这一轮主 run 的算力成本在千万美元
量级——这还没算数据团队、实验开销、失败的 run。**"预训练是零头"
这句话(对后训练而言)的另一面是:预训练是绝对多数,且不可重来**。

| 规模 | $C = 6ND$(D 按 Chinchilla 最优) | 单卡(16 GB 级)所需时间 |
|---|---|---|
| 1B / 20B tokens | ~1.2e20 | 数十年 |
| 7B / 140B tokens | ~5.9e21 | 数百年 |
| 70B / 1.4T tokens | ~5.9e23 | 数万年 |

这张表就是"个人不碰预训练"的定量理由。个人能做的是理解它的规律
(03 篇),以及在极小尺度(<100M 参数)上做教学性复现。

## 4. base model 的能与不能

主 run 产出的是 base model。它的能力画像:

**会**:续写任意文本、从 few-shot 示例中归纳模式(in-context
learning)、知识与推理的潜力已全部就位。

**不会**:对话(你问它答,它可能续写你的问题而不是回答)、听指令
("翻译这句话"可能被当成文本继续)、知道何时停止、拒绝有害请求。

这些"不会"正是后训练要补的——见 finetune 系列。评估 base model
也因此不能用聊天方式,要用 few-shot 续写(06 篇)。

## 6. 小结

- 预训练 = 在海量文本上做 next-token prediction,能力是预测压力的
  副产品;
- 项目结构:数据与外推实验是壁垒,主 run 是执行力;
- $C \approx 6ND$ 是全部成本讨论的锚点,7B 级训练已超出个人
  硬件几个数量级;
- base model 是"潜力完成、行为未定"的产物,后训练接力完成后者。
