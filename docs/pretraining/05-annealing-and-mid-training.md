# 退火与 Mid-training:主 run 之后、后训练之前

前置:[01-pretraining-overview.md](01-pretraining-overview.md)、
[04-large-scale-training.md](04-large-scale-training.md)(lr 调度)。
目标:理解预训练收尾阶段的两个关键操作——**退火(annealing)**
为什么能用很小的算力再挤出一截能力,以及长上下文是怎么在
mid-training 阶段扩展出来的。

## 1. 退火:最后的冲刺

**做法**:主 run(恒定或缓降 lr)结束后,用剩余 ~10% 的算力,
把 lr 快速降到接近 0,同时**混入最高质量的数据**(教科书、精选
代码、数学推理、人工精编语料)。

**为什么有效**(两个互补解释):

- 优化视角:恒定 lr 下权重在最优点附近"震荡",快速降 lr 让权重
  沉入一个更平坦、更优的极小值——SGD 末期衰减的经典的收益;
- 数据视角:好数据留在最后用,模型对它们的记忆最新鲜,且末期小
  lr 的更新更"精细",适合吸收高密度知识。

Llama-3 的报告实践:退火阶段的数据配比与主 run 显著不同(上调
高质量源),下游 benchmark 在退火阶段获得可观提升。**这是整个
预训练中"性价比最高的一段算力"**——用 10% 的算力买最后一截能力。

WSD schedule(04 篇 §4)把退火变成了标准产品形态:stable 阶段的
同一个 checkpoint,可以 decay 出不同版本做 A/B,选最好的当 base
发布。

## 2. Mid-training:一个新阶段的名字

"mid-training"是近年(Llama-3 报告起)对**预训练与后训练之间**
工作的统称,主要包括:

1. 退火(§1);
2. **长上下文扩展**(§3);
3. 领域倾斜(最终微调前的继续预训练,如数学模型加训数学语料)。

它值得单独命名,因为它的数据、lr 策略、评估方式都既不像主 run
(广谱、恒 lr)也不像后训练(行为对齐、极小 lr)。

## 3. 长上下文扩展:从 4K 到 128K 的技术链

问题:主 run 通常在 4K~8K 上下文训练(长序列训练太贵,attention
成本随长度平方增长),但产品需要 128K 甚至 1M。直接把在 4K 上
训好的模型用于 128K,会发生什么?

### 3.1 RoPE 外推为什么失效

RoPE 用旋转编码位置:位置 $m$ 的 query/key 按角度 $m\theta_i$ 旋转,
其中 $\theta_i = b^{-2i/d}$($b$ 为基频,经典 10000),$i$ 是维度
索引。相对位置 $m-n$ 的信息编码在旋转角差 $(m-n)\theta_i$ 里。

训练时模型只见过 $m < 4096$ 的角度。推理时位置冲到 128K,
**高维维度的旋转角超出训练见过的范围**——模型的位置理解完全
失效,perplexity 爆炸。注意:低频维度(小 $i$,周期长)其实外推
良好,出问题的是高频维度。

### 3.2 三种补救

| 方法 | 思路 | 特点 |
|---|---|---|
| 位置插值(PI) | 把位置索引线性压缩:$m \to m \cdot \frac{L_{\text{train}}}{L_{\text{target}}}$,让大位置落回训练范围 | 简单,需少量微调;高频维度分辨率被稀释 |
| NTK-aware | 不改位置,改基频 $b$(如 10000 → 500000),压缩各维度的有效频率 | 免微调外推尚可,但各维度一刀切 |
| **YaRN** | 按维度分段:高频维度不外推、低频维度插值,中间平滑过渡 | 效果最好,现代模型主流 |

### 3.3 但真正的长上下文是"训"出来的

以上方法解决的是"位置编码不失效",但**会用长上下文是一种能力,
不是编码性质**:模型要见过足够多"答案分散在长文档各处"的样本,
才学会在 100K token 里大海捞针。所以现代做法是:

```
改 RoPE 参数(YaRN 式)→ 分阶段加长度训练(8K → 32K → 128K,
每阶段混入比例递增的长文档数据)→ 大海捞针式评估
```

Llama-3 用了 6 个阶段把上下文从 8K 扩到 128K,每阶段都验证
短上下文能力不回退。这也解释了为什么"128K 上下文"的实际可用
长度常打折扣(NIAH 满分 ≠ 长文档推理可靠)——能力上限由长文
数据的质量与配比决定。

## 4. 课程学习:数据的先后顺序

受人类教育启发:先易后难。预训练中的证据与现状:

- 简单课程(按长度/质量排序)收益微弱且不稳;
- 真正有效的"课程"是**分阶段配比**(02 篇 §4):早期广谱数据打底,
  后期精品数据冲刺——退火本身就是课程学习的一个特例;
- 代码数据的位置:放早期(打底推理能力)与放退火(最后冲刺)
  都有实践,共识是"不能没有",位置是次要因素。

## 5. 对个人的意义

- 读模型报告时,长上下文宣传要追问三件事:RoPE 改了什么、
  分几个阶段训的、NIAH 之外的长文任务表现;
- 微调时同理:想教模型处理长输入,只用短数据训不出来——
  数据长度分布必须覆盖目标场景(finetune 07 篇的微观版);
- 退火思想可迁移:微调末期混入最高质量数据、降 lr 收尾,
  是值得 A/B 一试的技巧。

## 6. 小结

- 退火 = 快速降 lr + 高质量数据,10% 算力买最后一截能力,
  是性价比最高的一段训练;
- mid-training(退火、长上下文扩展、领域倾斜)是预训练与后训练
  之间一个真实存在的工程阶段;
- 长上下文 = 位置编码修正(YaRN)**+** 长文数据分阶段训练,
  前者让模型"能看",后者让模型"会用";
- 至此 base model 出炉,接力棒交给后训练(finetune 系列)。
