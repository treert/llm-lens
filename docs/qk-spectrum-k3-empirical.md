# QK 谱:Kimi-K3 实证结果

理论框架与预测见 [qk-spectrum.md](qk-spectrum.md)(§6.2 的预测表是本文的对照基准);
模型结构事实见 [kimi-k3.md](kimi-k3.md)。本文只记录**从 K3 开源权重静态提取的数据与观察**,
不与理论文档混写,便于对照整理。

数据由 `analysis/kimi_k3/` 的脚本生成(可复现):
`probe_structure.py` → `extract_qk_spectrum.py` → `plot_qk_spectrum.py` /
`analyze_head_types.py` / `analyze_shared_latent.py`;
原始数据在 `output/kimi_k3/`(npz + json),图在 `output/kimi_k3/figures/`。

## 0. 方法要点与适用范围

- 只分析 **24 个 MLA 全注意力层**(0-based 层号 3,7,11,…,91,92;config 层号 +1);
  69 个 KDA 线性注意力层不是 softmax(QK^T) 结构,不在 QK 谱框架内。
- K3 的 MLA 是 **NoPE**(config `mla_use_nope=true`,建模代码 `rotary_emb=None`):
  每头 192 维 = nope 128 维(经 `kv_b`)+ "rot" 64 维(**不旋转**,K 侧由 `kv_a` 直出、
  96 头共享)。谱分析对完整 192 维进行,同时记录 nope 块的能量占比。
- 每头 $M_h = W_{Qh}^\top W_{Kh}$(有效权重由两段低秩投影合成,RMSNorm 增益已折入;
  RMSNorm 的 $1/\mathrm{rms}(x)$ 是逐 token 标量,不属静态权重,未纳入)。
  用潜空间 Gram 复用计算,不构造 7168×7168 的 $M$;
  与直接法交叉核对,奇异值最大偏差 1.3e-14。
- 共 24 层 × 96 头 = **2304 个头**,每头 192 个奇异值。

## 2. 谱形态与范数增长

图:`figures/qk_spectrum_curves.png`(6 个代表层谱曲线 vs 随机基线)、
`figures/qk_metric_heatmaps.png`(4 项指标层×头热力图)。

- **谱曲线整体远离基线**:随机基线 σ ≤ ~1.3(Fuss-Catalan,‖M‖_F² ≈ 192),
  训练后中位谱从头几个 ~10 平缓降到尾部 ~10⁻²;任何头都不接近基线。
- **i≈64 处的台阶**:多数层的谱在第 64 个奇异值附近有可见的跌落,对应 nope(128 维)
  与 rot(64 维)两块能级的分界——MLA 两块结构在谱上留下的指纹。
- **σ1 层间轮廓**(逐层中位数):层 3 = 8.0 → 层 43 = 13.9 → 层 63~71 = 21~23 →
  **层 75 = 34.2(峰值)** → 层 92 = 17.5。最大值出现在层 83 头 62,σ1 = 99.3。
  中后段注意力 logit 的系统性偏移能力最强。
- **有效秩**:逐层中位 55(层 15)~ 150(层 63);全局最小为层 15 头 40,r_eff = 49.3。
  谱有集中但远非极端低秩。

## 3. 头分型:没有相似性头

数据:`head_types.json`;图:`figures/head_type_scatter.png`。

- sym(M) 分位数:min 0.982 / p10 1.265 / 中位 1.324 / p90 1.364 / max 1.396
  (√2 ≈ 1.414 为完全非对称上限)。
- 按文档锚点分型(sym<0.5 相似性 / 0.5~1.2 混合 / >1.2 序列):**0 / 57 / 2247**。
- σ 加权 mean(u_i·v_i):中位 0.12,最高 0.66(层 3 头 12,它也是 sym 最低头)。
- 解读:K3 MLA 头几乎清一色"序列匹配/方向变换"型,没有学成 W_Q ≈ W_K 的
  相似性匹配头。最"相似性"的头(sym≈0.98)也只偏离 √2 约 0.4。
  相似性匹配功能可能由共享 rot 通道或 KDA 层承担(见 §5 的 nope 占比)。

## 4. 共享潜库指纹(§6.3 的 MLA 版)

数据:`shared_latent_overlap.json`;图:`figures/shared_latent_overlap.png`。
做法:每头取 M 的 top-32 右奇异方向,用 576 维潜空间(512 kv + 64 rot)正交基坐标表示,
层内 C(96,2)=4560 对头两两算主视角;基线为 576 维中随机 32 维子空间(期望 k/n = 0.0556)。

- **重叠全面碾压基线**:层内均值 0.46(层 3~11)~ 0.86(层 87),为基线的 8.3~15.6 倍;
  任意两头 top-32 子空间的最大主视角余弦中位数 ≥ 0.96——任意两头至少共享一个方向。
- **随深度增强**:重叠均值从浅层 ~0.46 升到层 75~91 的 0.73~0.86。
- **占用很挤**:全部 96 头 top-32 方向堆叠后的有效秩只有 62~193(上限 576);
  层 87 最极端:重叠 0.86、占用有效秩 62——96 个头的主要匹配方向挤在约 1/9 的潜空间里。
- 对照组事实:潜空间本身接近满秩(q_a 有效秩 650~1500/1536,kv_a ~450~505/512),
  说明瓶颈不在潜空间容量,而在头侧对齐集中——与 §6.3"功能同质化/容量竞争"的预判一致。

## 5. 两个文档之外的新观察

1. **nope/rot 能量占比的层间分化**(热力图第 4 行):浅层(3~39)多数头 nope 能量占比
   中位数 < 0.15,层 15/27 甚至 ≈ 0.001——这些层的匹配几乎全部由 96 头共享的 64 维 rot
   通道承担;中后段(51~83)升到 0.19~0.35。σ1 全局最大头(层 83 头 62)的 nope 占比
   也只有 0.088。**共享通道承担的匹配远超"nope 为主、rope 为辅"的先验**——
   注意它是 NoPE,这 64 维不含位置信息,是纯粹的共享语义通道。
2. **间隔 12 层的周期带**:r_eff 与 nope 占比在层 3/15/27/39 出现同步极小,
   间隔恰为 attn_res_block_size=12(AttnRes block 边界,见 kimi-k3.md)。
   疑似跨 block 聚合改变了 block 首层的注意力角色,待验证。

## 6. 注意事项与局限

- 本分析是**纯权重静态分析**:未跑模型,结论描述的是 W_Q/W_K 编码的"匹配潜能",
  实际 logit 还受输入分布、RMSNorm 逐 token 标量、KDA/全注意力分工影响。
- rot 段 K 侧没有 kv_b 升维,其谱结构(64 维、全头共享)与 nope 段不对等,
  对比两块能量时需注意自由度差异(128 对 64)。
- 对齐矩阵元素符号有 SVD 符号任意性,本文只使用 |C| 与 u·v 这类符号不变量。
- 随机基线用同形状高斯 Monte Carlo(σ_w² = 1/7168),与 Fuss-Catalan 理论曲线等价。
